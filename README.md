## Задание 1. Отладка приложения «Фибоначчи»

### Источник
https://learn.microsoft.com/ru-ru/training/modules/dotnet-debug-visual-studio/4-use-visual-studio-debugger

### Описание программы
Программа вычисляет n-е число Фибоначчи. Последовательность начинается с 0 и 1, каждое следующее число равно сумме двух предыдущих.

### Найденная ошибка
В оригинальном коде условие цикла было `for (int i = 2; i < n; i++)`.  
При `n = 5` это даёт итерации `i = 2, 3, 4` (3 итерации), а нужно `i = 2, 3, 4, 5` (4 итерации).  
В результате программа возвращала `3` вместо правильного `5`.

### Исправление

// Было
for (int i = 2; i < n; i++)

// Стало
for (int i = 2; i <= n; i++)
### Использованные способы отладки
- Точка останова (Breakpoint) – на строке вызова `Fibonacci(5)`
- Условная точка останова – остановка при `i == 4`
- Пошаговое выполнение с заходом (Step Into, F11)
- Пошаговое выполнение с обходом (Step Over, F10)
- Окно «Локальные» (Locals)
- Окно «Контрольные значения» (Watch)
- Подсказки по данным (DataTips)

### XML-комментарии
Добавлены комментарии для метода `Fibonacci` с описанием параметра `n` и возвращаемого значения.

### Результат
| Было | Стало |
|------|-------|
| 3    | 5     |

## Задание 2. Отладка приложения «Галактики»

### Источник
https://learn.microsoft.com/ru-ru/visualstudio/debugger/debugging-absolute-beginners?view=vs-2022&tabs=csharp

### Описание программы
Программа выводит список галактик с названием, расстоянием в миллионах световых лет и типом галактики.

### Найденные ошибки
1. Неправильный тип свойства – `public object GalaxyType { get; set; }` вместо `public GType GalaxyType`
2. Неправильный доступ к свойству – в выводе использовалось `.GalaxyType` вместо `.GalaxyType.MyGType`
3. Опечатка в операторе switch – `case 'l'` (маленькая L) вместо `case 'I'` (большая I)

### Исправления

// 1. Исправлен тип свойства
public GType GalaxyType { get; set; }

// 2. Исправлен вывод
Console.WriteLine(theGalaxy.Name + "  " + theGalaxy.MegaLightYears + ",  " + theGalaxy.GalaxyType.MyGType);

// 3. Исправлена опечатка
case 'I': MyGType = "Irregular"; break;
### Использованные способы отладки
- Точка останова (Breakpoint) – на строке `Console.WriteLine` и в конструкторе `GType`
- Запуск отладчика (F5)
- Перезапуск отладчика (Ctrl+Shift+F5)
- Подсказки по данным (DataTips) – наведение на `theGalaxy.GalaxyType`
- Просмотр свойств объектов через значок лупы
- Пошаговое выполнение с заходом (Step Into, F11)
- Окно «Список ошибок» (Error List)

### XML-комментарии
Добавлены комментарии для класса `Galaxy`, класса `GType`, конструктора и всех свойств.

### Результат
Программа корректно выводит тип галактики (Spiral, Elliptical, Irregular, Lenticular) вместо имени класса `GType`.

**Ожидаемый вывод:**
Tadpole 400, Spiral
Pinwheel 25, Spiral
Cartwheel, 500, Lenticular
Small Magellanic Cloud 0.2, Irregular
Andromeda 3, Spiral
Maffei 1, 11, Elliptical

## Задание 3. Отладка приложения «Буквы»

### Источник
https://learn.microsoft.com/ru-ru/visualstudio/get-started/csharp/tutorial-debugger?view=vs-2022#create-a-project

### Описание программы
Программа собирает имя "fred smith" из массива символов и на каждой итерации отправляет приветственное сообщение с текущим именем и числом.

### Особенности
Данное приложение не содержало логических ошибок и использовалось для изучения базовых возможностей отладчика Visual Studio.

### Использованные способы отладки
- Точка останова (Breakpoint) – на строке `name += letters[i]` и в методе `SendMessage`
- Запуск отладчика (F5)
- Шаг с обходом (Step Over, F10)
- Шаг с заходом (Step Into, F11)
- Шаг с выходом (Shift+F11)
- Подсказки по данным (DataTips) – наведение на `letters`, `name`, `a[i]`
- Окно «Локальные» (Locals)
- Окно «Автозапуск» (Autos)
- Окно «Контрольные значения» (Watch) – отслеживание переменной `name`
- Окно «Стек вызовов» (Call Stack)
- Выполнить до щелчка (Run to Click)
- Выполнить до курсора (Ctrl+F10)
- Перезапуск отладчика (Ctrl+Shift+F5)
- Остановка отладки (Shift+F5)

### XML-комментарии
Добавлены комментарии для класса `ArrayExample`, методов `Main` и `SendMessage`, а также для параметров методов.

### Результат
Программа выводит 10 сообщений, последовательно формируя имя "fred smith":
Hello, f! Count to 1
Hello, fr! Count to 2
Hello, fre! Count to 3
Hello, fred! Count to 4
Hello, fred ! Count to 5
Hello, fred s! Count to 6
Hello, fred sm! Count to 7
Hello, fred smi! Count to 8
Hello, fred smit! Count to 9
Hello, fred smith! Count to 10
